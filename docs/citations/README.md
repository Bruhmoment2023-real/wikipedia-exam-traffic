# Citation library

- **Entries:** 259 BibTeX (`references.bib`), 259 RIS (`references.ris`), de-duplicated by DOI / arXiv id.
- **Identifiers found in the folder:** 194 DOIs + 71 arXiv ids, from 119 text files (prior-work notes, design and outline files, follow-ups, evidence table, reading notes).
- **Source of fields:** Crossref's BibTeX/RIS transform (or doi.org content negotiation, or the arXiv API); no field was typed by hand.
- **Not resolved (6):** `10.1016/j` (Crossref 404; doi.org content negotiation failed); `10.1016/j.jeconom.2023` (Crossref 404; doi.org content negotiation failed); `10.1109/icse48619` (Crossref 404; doi.org content negotiation failed); `10.1177/tobeassigned` (Crossref 404; doi.org content negotiation failed); `10.18653/v1/2021` (Crossref 404; doi.org content negotiation failed); `10.18653/v1/2024` (Crossref 404; doi.org content negotiation failed)
- **Known limit:** only sources with a DOI or arXiv id are captured. A source cited by title only (a report, a government page, a dataset, a statute) is not in the library; add it by hand in Zotero.
- **In BibTeX but not RIS:** 0.

## Import into Zotero
1. Zotero > File > Import... > choose `references.bib` (or `references.ris`) > keep 'Place imported collections and items into new collection'.
2. Check the few entries with odd capitalisation or missing pages; Crossref's metadata is only as good as the publisher's deposit.
